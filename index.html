    🔍 인재풀 검색
    ① 한 번만 설정 — 북마크릿 등록

    아래 버튼을 즐겨찾기 바(북마크바)로 드래그해서 등록하세요. (안 보이면 Ctrl+Shift+B로 즐겨찾기 바를 먼저 켜주세요)

    📋 인재정보 복사

    등록 후엔 게임잡 인재검색 결과 화면에서 이 버튼만 누르면 그 페이지의 인재 정보가 자동으로 클립보드에 복사돼요. (F12 필요 없음!)

    ② 매번 할 일
    1. 게임잡 인재검색에서 직무·경력·키워드 등 원하는 조건으로 검색하세요.
    2. 결과 화면에서 등록해둔 "📋 인재정보 복사" 북마크릿을 클릭하세요 (자동으로 클립보드 복사됨).
    3. 아래 칸에 붙여넣고(Ctrl+V) "분석하기"를 누르세요. 다음 페이지도 같은 방식으로 반복하면 자동으로 누적돼요 (중복 인물은 자동 제거).
    북마크릿이 안 될 때 (구형 브라우저 등) 결과 화면에서 F12 → Network 탭 → 목록에서 _Resume_List 클릭 → Response 탭 내용을 전체 복사(Ctrl+A, Ctrl+C)해서 아래에 붙여넣어도 똑같이 동작해요.
